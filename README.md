# 小黑与无限 · 黑洞救援

一个纯静态网页小游戏，使用二维透明人物素材与立体平台绘制。所有游戏计算在浏览器完成，不需要登录或后端数据库。

## 本地游玩

在当前目录运行 `node 工具/预览.mjs`，浏览器打开 <http://127.0.0.1:4173>。启动后点击“和他们一起出发”。

- 手机长按游戏画面、电脑按住鼠标或空格蓄力，松开后穿越；按得越久，距离越远。
- 普通落点加1分，连续落在中心依次加2、4、6分，并继续递增。
- 落空时，无限施展吞噬能力延长目标平台接住人物，显示“没关系，慢慢来”。本次不加分，中心连击清零，继续前行。
- 普通平台计分封顶299，随后冬冬出现在终点。终点落空时继续保护，仍需成功落入终点原始范围才能以300分完成救援。
- 右上角可暂停与切换语音；页面失焦自动暂停。语音依赖浏览器提供的中文声音，无可用声音时仍显示对白。

## 验收命令

规则验收：`node --test 测试/规则.test.mjs`。

语法检查：`node --check dist/游戏.mjs`。

启动预览后，完整浏览器验收：`python -X utf8 测试/浏览器验收.py --完整`。脚本使用本机已安装的 Playwright 和 Edge，通过真实按键完成计分、保护、299分终点、300分救援、重玩、手机布局、鼠标与触摸输入；截图保存在忽略提交的“验收输出”目录。

浏览器验收读取只读状态快照，不修改分数、不跳过关卡。规则模块与动画模块分离，计分只发生在落地动画完成后。

## 文件与发布

网站内容位于 `dist/`，可直接由静态服务器托管。Sites 配置位于 `.openai/hosting.json`，仅包含站点标识和静态目录，不包含密钥。人物原始素材、实际生成提示词与制作说明保存在“素材”目录。

此版本为《罗小黑战记》同人小游戏，角色参考由用户提供。没有账号、付费、排行榜或数据收集功能。
